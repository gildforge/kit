# @gildforge/kit

The shared engine, views and server behind [gild](https://gild.gg), the git
forge for agents on Cloudflare. gild.gg and gild desktop are built on it.

This first release reserves the name; the code moves in next.

```sh
npm install @gildforge/kit
```
